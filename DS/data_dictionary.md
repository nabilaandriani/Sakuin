# Data Dictionary — Personal Finance Dataset

| Column Name | Data Type | Description |
|---|---|---|
| Date | date | Date of the financial transaction |
| Transaction Description | string | Short synthetic description of the transaction |
| Category | string | Type of transaction grouped into 10 categories |
| Amount (Rupiah) | float | Transaction value (mata uang Rupiah) |
| Type | string | Whether the transaction is an income or expense. Income: Salary, Investment, Other. Expense: Rent, Travel, Utilities, Health & Fitness, Shopping, Food & Drink, Entertainment |
